# NDOKI Nigeria

NDOKI Nigeria is a modern, visually rich landing website for a heritage fashion brand inspired by Nigerian culture, craftsmanship, and the Akwete textile tradition. The site presents the brand story, featured collections, and key sections such as shop, about, and contact in a polished, responsive experience.

## Features

- Responsive landing page design
- Smooth scrolling and animated section reveals
- Hero image slider with autoplay and navigation controls
- Mobile-friendly navigation menu
- Featured collection and brand story sections
- Newsletter and contact form UI with interactive feedback

## Project Structure

- index.html - Main page structure
- assets/styles.css - Site styling and responsive layout
- assets/main.js - Interactive behavior such as sliders, navigation, and animations

## Getting Started

Open the project in a browser directly:

1. Open index.html in your preferred browser, or
2. Serve the folder locally with a simple web server, for example:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000 in your browser.
